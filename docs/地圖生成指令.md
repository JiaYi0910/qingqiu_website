2026-10-20 用這段指令生成了 `images/map/qingqiu-map.jpg`（原圖在 Downloads：青丘幻境水彩奇境地图.png，1536×1024）。

和舊地圖比改了：雷動台 → 雷劫台；左上「異鄉」→ 上方「往北・冰原」；西邊的大湖改叫翠湖（小說裡的鏡湖在雲野）；
雲野畫在右下角霧的另一邊（第三十四章從拜月台往右下角看得到雲野的燈）；加上昭昭出生的南邊櫻林。

```text
請畫一張手繪水彩風的奇幻古地圖，橫式 3:2（例如 1536×1024）。
米黃色羊皮紙底，四角有金棕色雕花邊框，左下角有指北針（北在上）。
古風、溫柔、細緻：山用青綠色加白雪，櫻花用淡粉色，燈火用暖橘色。
每個地名寫在小小的米色木牌上，用繁體中文，字要清楚、不能多字或少字。
地點之間用褐色虛線小路連起來。地圖上的地點如下（照方位擺）：

【北邊】
・松濤山：西北，連綿的雪頂松樹山。
・初雪坡：在松濤山山腳下（北邊中間）。一道長長的石階通到山門，山門口掛著一盞亮著橘黃色光的燈籠；山門後是有一棵大松樹的庭院和幾間屋子；後山有一個小小的深色水潭，被雪和松樹圍著。
・石磬峽：東北，很陡的峽谷加一道瀑布，崖頂上有一棵很老的桃樹。
・山茶嶺：最東北，開紅色山茶花的山嶺。
・地圖上緣中間畫一個往上的箭頭，寫「往北・冰原」。

【中間】
・青丘之巔：地圖正中央最高的一座山，山頂插進雲裡。
・拜月台：在青丘之巔的山肩上，一座白玉圓形高台，一道非常長的石階一路往上，旁邊畫一輪月亮。
・雷劫台：在青丘之巔另一側的崖上，一座白玉圓台，四周圍著白玉石欄。
・月見原：青丘之巔西邊，一片月光下的草原。
・霞霧泉：西邊，有瀑布和霧氣的泉水。
・翠湖：西邊一座大湖，湖中有小島「北辰島」（島上一座小亭和棧橋）；湖北岸是開著櫻花的「朝霞岸」；湖南邊是一大片森林「翠湖林」。
・聽雨亭：東邊海岸山崖上的一座亭子。
・螢火溪：從石磬峽流下來、往東流進海裡的小溪。
・古槐鎮：東邊一座有老槐樹的小鎮。

【南邊】
・星燈巷：青丘之巔南邊的狐妖市街，屋簷下、竹竿上掛滿上千盞燈籠，連成一條光河。
・稻香里：星燈巷再往南，一格一格的稻田。
・麥浪田：一片金黃色的麥田。
・古井村：有一口古井的小村子。
・風鈴谷：西南的山谷，樹上掛滿風鈴，有一道小瀑布。
・櫻林：南邊一大片粉紅色櫻花林，最大的那棵櫻樹底下有一間小屋。
・雲棲渡：青丘最南端的渡口，有木棧橋和一棵老柳樹，橋邊泊著幾朵像小船的白雲。

【東邊】
・東海：地圖右邊上半部的海。海灣「潮音灣」裡有帆船，外海有一群小礁石「浮貝礁」。

【右下角：雲野】
・雲棲渡外面是一大片白茫茫的霧和雲海，把青丘和人間隔開；從雲棲渡畫一條白雲飄過霧的虛線。
・霧的另一邊、地圖右下角，是一小片溫暖的綠色草野，寫「雲野」（沒有雪，比青丘小、比青丘暖）。裡面有：
　- 「昭昭的家」：一間小木屋，竹籬笆門口掛一盞亮著的燈，門邊一棵小小的櫻花樹，院子裡一棵桂花樹。
　- 「桃林」：小屋東邊一片結著紅桃子的桃樹林。
　- 「鏡湖」：一個像鏡子一樣清亮的小湖。
　- 「竹影坡」：湖邊一片長滿竹子的小山坡。
桃林、鏡湖、竹影坡只畫在右下角的雲野，青丘裡不要有。
```
