# 地點插畫與地圖的拼盤指令

三張拼盤。生好以後放進 `墨染櫻雪\插畫` 或直接傳給 Claude，會裁好放進地點頁和地圖小卡。

---

## 拼盤一：青丘的九個地方

```text
請畫一張橫式 3:2 的風景拼盤（例如 1536×1024），分成 3 欄 × 3 列，一共 9 個大小一樣的格子。
格子之間留一條細細的米白色空隙，每一格是一張獨立的風景小圖：畫面不能跨格，整張圖不要寫任何文字。
畫風：手繪水彩感的古風奇幻風景插畫，柔和的光，顏色溫柔，像一張米黃色羊皮紙水彩地圖上的風景。
以風景為主，不要畫清楚的人物（遠處很小的狐狸身影可以）。
從左上到右下依序是：

1. 松濤山：連綿的雪頂山脈，山坡長滿高大的松樹，針葉上積著雪，冷冷的藍白色調。
2. 青丘之巔：一座非常高的山，山頂插進雲裡；山頂的雲黑得像墨，雲裡隱約有雷光。
3. 石磬峽：很陡的峽谷和一道瀑布，崖頂長著一棵很老很老的桃樹，枝頭掛著幾顆秋天的桃子。
4. 月見原：月光底下的一大片草原，又大又圓的月亮，草葉泛著銀光，遠處有一隻小小的白兔。
5. 稻香里：一格一格的稻田，月光下泛著銀光，田邊立著一個稻草人，遠處是一條掛滿燈籠的光河。
6. 雲棲渡：木頭搭的渡口和棧橋，一棵很老的柳樹，柳樹下用繩子繫著幾朵像小船一樣的白雲；渡口外是一大片白茫茫的霧。
7. 南邊的櫻林：滿山粉紅色的櫻花，開得像雲一樣；最大的那棵櫻樹底下有一間小小的木屋，花瓣一片一片落下來。
8. 古井村：山腳下的小村子，村子中間有一口長著青苔的古井，幾間小屋，屋頂飄著炊煙。
9. 雷劫台：山頂上一整塊白玉鋪成的圓台，四周圍著白玉石欄，石欄上有一段並排的深深裂痕；天空壓著深色的雷雲，台上沒有人。
```

## 拼盤二：雲野、人間、遠方的九個地方

```text
請畫一張橫式 3:2 的風景拼盤（例如 1536×1024），分成 3 欄 × 3 列，一共 9 個大小一樣的格子。
格子之間留一條細細的米白色空隙，每一格是一張獨立的風景小圖：畫面不能跨格，整張圖不要寫任何文字。
畫風：手繪水彩感的古風奇幻風景插畫，柔和的光，顏色溫柔，像一張米黃色羊皮紙水彩地圖上的風景。
以風景為主，不要畫清楚的人物（遠處很小的身影可以）。
從左上到右下依序是：

1. 雲野：一大片被微風吹得起伏的綠色草野，天空很藍，雲很軟；遠處有幾間屋簷下掛著風鈴的小屋。
2. 桃林：一片結滿紅桃子的桃樹林，樹下放著竹籃和一台小推車，早晨的陽光。
3. 鏡湖：像鏡子一樣清亮的小湖，倒映著天上的雲，湖邊有草地和幾隻白鷺。
4. 竹影坡：湖邊一片長滿竹子的小山坡，圓圓的月亮掛在竹林上面，竹影搖晃。
5. 桑溪：鄉下的小村子，村口有一棵非常老的桑樹，樹幹粗得三個人都抱不住；冬天下著小雪，樹下有兩座小小的墳，墳前擺著一碗清水和饅頭。
6. 杏花村：山裡的小村子，滿山白色和粉色的杏花開得像雪一樣；村口有一棵老杏樹，和一間當作私塾的小祠堂。
7. 京城：很大的古代城市，屋頂一片連著一片，街上燈火通明、人來人往；冬天，但是沒有下雪。
8. 獵戶小屋：深山裡一間破舊的小木屋，屋頂補著茅草；屋後有一條小溪，溪水中間有一塊大石頭；月圓的夜晚，空中飄著櫻花花瓣。
9. 北方冰原：一望無際的冰原，只有冰和風；一間用石頭和冰砌的小屋，窗戶亮著一盞燈；門口一棵開滿花的櫻樹，每一片花瓣的邊上都暈著淡淡的墨色。
```

## 拼盤三：初雪坡師門圖、人間地圖

```text
請畫一張橫式 3:2 的拼盤（例如 1536×1024），左右分成兩張一樣大的直式地圖，中間留一條細細的米白色空隙。
兩張是獨立的圖，畫面不能跨過中間的空隙。
畫風：手繪水彩風的奇幻古地圖，米黃色羊皮紙底，金棕色細邊框，溫柔細緻。
每個地名寫在小小的米色木牌上，用繁體中文，字要清楚、不能多字或少字；地點之間用褐色虛線小路連起來。北在上。

【左邊：初雪坡・師門】由下往上：
・最下面：「坡下的雪窩」，雪地裡一個背風的小雪窩；旁邊停著一朵白雲。
・往上是一道長長的石階，標「九十九階」，石階正中間有一條掃乾淨的窄路，兩邊是積雪；石階中段旁邊的石壁上刻著一隻小狐狸，標「第四十三階」。
・石階頂端是「山門」：一座木造山門，屋簷下掛著一盞亮著橘黃色光的燈籠，門口有兩根柱子。
・山門裡面是「庭院」：中間一棵老得看不出年紀的大松樹，樹下一張石桌，四周圍著迴廊。
・庭院左邊是「西廂」，右邊是「東廂」，上面是「北廂」；西廂旁邊一間小屋標「師父的屋子」；東廂旁邊一間有煙囪的小屋標「灶房」。
・北廂後面是「後院」，地上鋪著石板。
・最上面是「後山」：松林圍著一個圓圓的深色小水潭，標「寒潭」，潭中間有一塊平平的黑石頭，潭邊有一塊大石頭。
・右上角畫一個往上的箭頭，寫「往拜月台」。

【右邊：人間】
・最上面是一大片白茫茫的霧，霧裡飄出一朵白雲，標「雲棲渡・往青丘」。
・霧下面偏右是「柳渡鎮」：一條河、一座石橋，河邊一排柳樹，幾間屋子。
・柳渡鎮左邊是一片綠色草野，標「雲野」，裡面有一間小木屋和竹籬笆。
・柳渡鎮往南，進到山裡，是「杏花村」，滿山杏花。
・再往南，翻過三座山、渡過一條河，深山裡有一間小木屋，標「獵戶小屋」，屋後有小溪。
・獵戶小屋附近有一個山路的岔口，標「岔口」：一條路往右（東）通到「桑溪」（村口一棵大桑樹），一條路往上（北）通回霧裡的雲棲渡。
・左下角畫一個往外的箭頭，寫「往京城」。
```
